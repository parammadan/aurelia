## 2. Full contents of `src/Aurelia.Core`

### Events.cs
```csharp
// ─────────────────────────────────────────────────────────────────────────────
// AURELIA CORE. Design before code: every shape in this file traces to an
// accepted ADR in docs/adr — see 0004–0013 for the event model.
// ─────────────────────────────────────────────────────────────────────────────
namespace Aurelia.Core;

/// <summary>
/// Envelope for every immutable session event. Current state is a fold over
/// the log; the log is the only durable truth.
///
/// Coordinates (ADR-0007): each session is one flat, totally-ordered log.
/// <see cref="TurnOrdinal"/> identifies the activation (a user-input-to-
/// response cycle, or one autonomous activation) and <see cref="StepOrdinal"/>
/// the external call within it, assigned in issue order. Outcome events
/// inherit their intent's coordinates (ADR-0012), so consumers must order by
/// <see cref="Sequence"/>, never by coordinates.
///
/// <see cref="RecordedAt"/> is observability metadata only (ADR-0006): core
/// logic never reads it, and it never influences a decision. Logical time
/// arrives through <see cref="TimeRequested"/>/<see cref="TimeProvided"/>.
///
/// <see cref="SchemaVersion"/> increments per event type when its shape
/// changes; upcasters lift stored events to the current shape on read
/// (ADR-0009).
/// </summary>
public abstract record SessionEvent
{
    public required string SessionId { get; init; }
    public required long Sequence { get; init; }
    public required int TurnOrdinal { get; init; }
    public required int StepOrdinal { get; init; }
    public int SchemaVersion { get; init; } = 1;
    public required DateTimeOffset RecordedAt { get; init; }
}

// ── Session lifecycle ────────────────────────────────────────────────────────

public sealed record SessionStarted : SessionEvent
{
    public required string Goal { get; init; }
}

/// <summary>Opens a new turn (ADR-0007).</summary>
public sealed record UserMessageReceived : SessionEvent
{
    public required string Content { get; init; }
}

public sealed record AgentMessageSent : SessionEvent
{
    public required string Content { get; init; }
}

public sealed record SessionCompleted : SessionEvent
{
    public required string FinalStateJson { get; init; }
}

/// <summary>
/// Second terminal state (ADR-0017): the session failed and, after unwinding,
/// is parked for human resolution. Exactly one of
/// <see cref="SessionCompleted"/> or <see cref="SessionFailed"/> may appear.
/// </summary>
public sealed record SessionFailed : SessionEvent
{
    public required string Reason { get; init; }
    public required IReadOnlyList<string> CompensatedKeys { get; init; }
    public required IReadOnlyList<string> UncompensatedKeys { get; init; }
}

// ── External calls: intent phase (ADR-0008) ──────────────────────────────────
// An intent is durable BEFORE execution begins. An intent with no terminal
// outcome means the call may have executed and may have had side effects.

/// <summary>
/// Base for all intent events. The idempotency key identifies the logical
/// call, is identical across retry attempts, and is pure arithmetic over the
/// envelope stamps (ADR-0005, ADR-0010) — never stored state.
/// </summary>
public abstract record CallRequested : SessionEvent
{
    public string IdempotencyKey => $"{SessionId}/{TurnOrdinal}/{StepOrdinal}";
}

public sealed record ToolCallRequested : CallRequested
{
    public required string ToolName { get; init; }
    public required string ArgumentsJson { get; init; }
}

/// <summary>
/// Records the FULL inputs — exact prompt, model, parameters, config version —
/// so that re-execution and counterfactual replay remain possible without a
/// schema migration (ADR-0004).
/// </summary>
public sealed record ModelCallRequested : CallRequested
{
    public required string ModelId { get; init; }
    public required string PromptJson { get; init; }
    public required string ParametersJson { get; init; }
    public required string ConfigVersion { get; init; }
}

/// <summary>
/// Human approval is a slow external call (ADR-0011): "paused awaiting
/// approval" is a derived condition — this intent without an outcome — not a
/// stored state. Policy and optional expiry per ADR-0013.
/// </summary>
public sealed record ApprovalRequested : CallRequested
{
    public required string Question { get; init; }
    public required string ApproverPolicy { get; init; }
    public DateTimeOffset? ExpiresAt { get; init; }
}

/// <summary>
/// Saga compensation is itself an external call (ADR-0015): this intent is
/// durable before the compensating action runs, and its outcomes arrive under
/// the compensation's own key. <see cref="CompensatesKey"/> must reference a
/// recorded intent. Unwinding runs in reverse order of success.
/// </summary>
public sealed record CompensationRequested : CallRequested
{
    public required string ToolName { get; init; }
    public required string ArgumentsJson { get; init; }
    public required string CompensatesKey { get; init; }
}

/// <summary>Injected logical time (ADR-0006): core asks, the runtime answers
/// with a recorded <see cref="TimeProvided"/>.</summary>
public sealed record TimeRequested : CallRequested;

/// <summary>Injected randomness (ADR-0006).</summary>
public sealed record RandomRequested : CallRequested
{
    public int? MaxExclusive { get; init; }
}

// ── External calls: outcome phase (ADR-0008, ADR-0010, ADR-0012) ─────────────
// Outcomes inherit their intent's turn/step coordinates; a logical call is one
// intent, zero or more numbered attempt failures, and at most one terminal
// outcome. Replay substitutes the terminal outcome (ADR-0004).

public abstract record CallOutcome : SessionEvent
{
    public required int Attempt { get; init; }

    public string IdempotencyKey => $"{SessionId}/{TurnOrdinal}/{StepOrdinal}";
}

public sealed record ToolCallSucceeded : CallOutcome
{
    public required string ResultJson { get; init; }
}

public sealed record ModelCallSucceeded : CallOutcome
{
    public required string OutputJson { get; init; }
}

public sealed record ApprovalResolved : CallOutcome
{
    public required bool Approved { get; init; }
    public required string ApproverId { get; init; }
}

/// <summary>Terminal outcome produced when an approval's expiry fires; the
/// expiry itself arrives as an injected-time event (ADR-0013).</summary>
public sealed record ApprovalExpired : CallOutcome;

public sealed record TimeProvided : CallOutcome
{
    public required DateTimeOffset Value { get; init; }
}

public sealed record RandomProvided : CallOutcome
{
    public required int Value { get; init; }
}

/// <summary>Non-terminal: attempt <see cref="CallOutcome.Attempt"/> failed and
/// the call will be retried under the same key (ADR-0010).</summary>
public sealed record CallAttemptFailed : CallOutcome
{
    public required string Error { get; init; }
}

/// <summary>Terminal failure: retries exhausted or the error is not
/// retryable. For side-effectful calls this is what triggers the saga unwind
/// (ADRs 0015–0017).</summary>
public sealed record CallFailed : CallOutcome
{
    public required string Error { get; init; }
}
```

## 3. The kill/resume test, verbatim, and its CI status

**Runs in CI: yes.** `.github/workflows/ci.yml` runs `dotnet test` on
ubuntu-latest for every push to `main` and every PR; these tests execute a
real `Process.Kill(entireProcessTree: true)` (SIGKILL) against a real child
`dotnet` host. The eval suite runs as a third CI step. All runs to date are
green; the suite also passes locally on macOS.

```csharp
// THE CONTRACT (ADR-0002): kill the host with SIGKILL mid-tool-call; a fresh
// process must resume the session from the event log and complete it with the
// correct final state. Any change that breaks this test does not merge.
using System.Diagnostics;
using System.Text;
using System.Text.Json;
using Aurelia.Core;
using Aurelia.Runtime;
using Xunit;

namespace Aurelia.CrashTests;

public class CrashRecoveryTests
{
    private static readonly TimeSpan StartupTimeout = TimeSpan.FromSeconds(90);
    private static readonly TimeSpan CompletionTimeout = TimeSpan.FromSeconds(120);

    [Fact]
    public async Task Session_killed_mid_tool_call_resumes_and_completes_with_correct_final_state()
    {
        var workDir = Directory.CreateTempSubdirectory("aurelia-crash-");
        try
        {
            var storeDir = Path.Combine(workDir.FullName, "store");
            var signalDir = Path.Combine(workDir.FullName, "signals");
            Directory.CreateDirectory(storeDir);
            Directory.CreateDirectory(signalDir);

            const string sessionId = "crash-test-session";
            const string goal = "look up order 1234";
            var blockFile = Path.Combine(signalDir, "block");

            // Phase 1: block the tool, start the host, and SIGKILL it once the
            // tool call is provably in flight.
            File.WriteAllText(blockFile, "");
            var firstRunOutput = new StringBuilder();
            using (var victim = StartHost(sessionId, goal, storeDir, signalDir, firstRunOutput))
            {
                await WaitUntilAsync(
                    () => Directory.EnumerateFiles(signalDir, "*.started").Any(),
                    StartupTimeout,
                    $"tool never started; host output:\n{firstRunOutput}");
                victim.Kill(entireProcessTree: true);
                victim.WaitForExit();
            }

            var store = new FileEventStore(storeDir);
            var afterCrash = await store.ReadAsync(sessionId);
            Assert.Contains(afterCrash, e => e is ToolCallRequested);
            Assert.DoesNotContain(afterCrash, e => e is CallOutcome);
            Assert.DoesNotContain(afterCrash, e => e is SessionCompleted);

            // Phase 2: unblock the tool and start a fresh process, which must
            // resume from the log and finish.
            File.Delete(blockFile);
            var secondRunOutput = new StringBuilder();
            using (var survivor = StartHost(sessionId, goal, storeDir, signalDir, secondRunOutput))
            {
                var exited = survivor.WaitForExit((int)CompletionTimeout.TotalMilliseconds);
                if (!exited)
                    survivor.Kill(entireProcessTree: true);
                Assert.True(exited, $"resumed host did not exit; output:\n{secondRunOutput}");
                Assert.Equal(0, survivor.ExitCode);
            }

            var finalLog = await store.ReadAsync(sessionId);
            Assert.Single(finalLog.OfType<SessionStarted>());
            var request = Assert.Single(finalLog.OfType<ToolCallRequested>());
            var success = Assert.Single(finalLog.OfType<ToolCallSucceeded>());
            var completed = Assert.Single(finalLog.OfType<SessionCompleted>());

            // ADR-0010/0012: the outcome pairs with its intent by key, which
            // both phases derive from the same inherited coordinates.
            Assert.Equal($"{sessionId}/0/0", request.IdempotencyKey);
            Assert.Equal(request.IdempotencyKey, success.IdempotencyKey);
            Assert.Equal(1, success.Attempt);

            using var finalState = JsonDocument.Parse(completed.FinalStateJson);
            Assert.Equal(goal, finalState.RootElement.GetProperty("echoed").GetString());

            // ADR-0004: the crashed-and-recovered session replays to exactly
            // the state the live run produced.
            var replayed = await new ReconstructionReplayEngine(store).ReplayAsync(sessionId);
            Assert.Equal(completed.FinalStateJson, replayed.FinalStateJson);
        }
        finally
        {
            workDir.Delete(recursive: true);
        }
    }

    [Fact]
    public async Task Case_resolution_survives_sigkill_mid_service_credit_with_exactly_one_credit()
    {
        var workDir = Directory.CreateTempSubdirectory("aurelia-case-crash-");
        try
        {
            var storeDir = Path.Combine(workDir.FullName, "store");
            var signalDir = Path.Combine(workDir.FullName, "signals");
            Directory.CreateDirectory(storeDir);
            Directory.CreateDirectory(signalDir);

            const string sessionId = "case-crash";
            const string goal = "service credit for case 42";
            var blockFile = Path.Combine(signalDir, "block");
            File.WriteAllText(blockFile, "");

            var firstRun = new StringBuilder();
            using (var victim = StartHost(sessionId, goal, storeDir, signalDir, firstRun, "case-resolution"))
            {
                await WaitUntilAsync(
                    () => Directory.EnumerateFiles(signalDir, "*.started").Any(),
                    StartupTimeout,
                    $"service credit never started; host output:\n{firstRun}");
                victim.Kill(entireProcessTree: true);
                victim.WaitForExit();
            }

            var store = new FileEventStore(storeDir);
            var afterCrash = await store.ReadAsync(sessionId);
            var creditIntent = Assert.Single(afterCrash.OfType<ToolCallRequested>(),
                r => r.ToolName == "issue_service_credit");
            Assert.DoesNotContain(afterCrash.OfType<CallOutcome>(),
                o => o.IdempotencyKey == creditIntent.IdempotencyKey);
            Assert.DoesNotContain(afterCrash, e => e is SessionCompleted or SessionFailed);

            File.Delete(blockFile);
            var secondRun = new StringBuilder();
            using (var survivor = StartHost(sessionId, goal, storeDir, signalDir, secondRun, "case-resolution"))
            {
                var exited = survivor.WaitForExit((int)CompletionTimeout.TotalMilliseconds);
                if (!exited)
                    survivor.Kill(entireProcessTree: true);
                Assert.True(exited, $"resumed host did not exit; output:\n{secondRun}");
                Assert.Equal(0, survivor.ExitCode);
            }

            // The money assertion: exactly one credit in the ledger.
            var ledger = File.ReadLines(Path.Combine(storeDir, "ledger.jsonl"))
                .Select(l => JsonDocument.Parse(l).RootElement.GetProperty("type").GetString()!)
                .ToArray();
            Assert.Equal(["credit"], ledger);

            var finalLog = await store.ReadAsync(sessionId);
            var completed = Assert.Single(finalLog.OfType<SessionCompleted>());
            var replayed = await new ReconstructionReplayEngine(store).ReplayAsync(sessionId);
            Assert.Equal(completed.FinalStateJson, replayed.FinalStateJson);
        }
        finally
        {
            workDir.Delete(recursive: true);
        }
    }

    private static Process StartHost(
        string sessionId, string goal, string storeDir, string signalDir, StringBuilder output,
        string agent = "echo")
    {
        // The Runtime executable is copied into the test output directory by
        // the project reference.
        var runtimeDll = Path.Combine(AppContext.BaseDirectory, "Aurelia.Runtime.dll");
        Assert.True(File.Exists(runtimeDll), $"runtime not found at {runtimeDll}");

        var psi = new ProcessStartInfo("dotnet")
        {
            ArgumentList =
            {
                runtimeDll,
                "run",
                "--session-id", sessionId,
                "--goal", goal,
                "--store-dir", storeDir,
                "--agent", agent,
            },
            RedirectStandardOutput = true,
            RedirectStandardError = true,
        };
        psi.Environment[BlockableEchoTool.SignalDirVariable] = signalDir;

        var process = Process.Start(psi)!;
        process.OutputDataReceived += (_, e) => { if (e.Data is not null) lock (output) output.AppendLine(e.Data); };
        process.ErrorDataReceived += (_, e) => { if (e.Data is not null) lock (output) output.AppendLine(e.Data); };
        process.BeginOutputReadLine();
        process.BeginErrorReadLine();
        return process;
    }

    private static async Task WaitUntilAsync(Func<bool> condition, TimeSpan timeout, string failureMessage)
    {
        var deadline = DateTimeOffset.UtcNow + timeout;
        while (DateTimeOffset.UtcNow < deadline)
        {
            if (condition())
                return;
            await Task.Delay(100);
        }
        Assert.Fail(failureMessage);
    }
}
```

14. `ApprovalExpired` as its own outcome type rather than a `CallFailed` reason code. Flagged in PR #1; unreviewed.
15. Exact envelope field names/types (`Sequence: long`, ordinals `int`, `SchemaVersion: int = 1`, `RecordedAt: DateTimeOffset`).
16. **Stamping conventions for non-call events** (no ADR): `SessionStarted` at step 0; `SessionCompleted` at step = script length; compensations and `SessionFailed` take `max(StepOrdinal)+1`. Everything to date is `TurnOrdinal = 0` — multi-turn is entirely unexercised.
17. **Persistence format**: JSONL envelope `{type: <CLR type name>, data: {...}}`, camelCase, type discriminator = class name. This couples stored data to type names; renaming an event class breaks old logs (mitigable by upcasters/aliases, but that convention was never decided by the owner).
18. Missing `schemaVersion` in stored payloads is treated as version 0.

### Runtime semantics (no ADR exists for these)
19. **Retry policy**: `maxAttempts = 2`, immediate retries (no backoff); terminal `CallFailed` duplicates the last attempt's error text. ADRs explicitly defer retry policy; this provisional policy is the assistant's.
20. **Torn-tail tolerance** in `FileEventStore`: a `JsonException` on the final line only is swallowed (treated as a never-durable event). This is load-bearing crash-recovery semantics decided in code.
21. Replay of a **failed** session returns a synthesized JSON (`{status, reason, compensatedKeys, uncompensatedKeys}`) rather than throwing; replay of an **in-flight** session throws `SessionNotCompletedException`. The failed-state JSON shape is duplicated between driver and replay engine and compared byte-for-byte in tests.
22. The specific **integrity invariants** enforced by replay (strictly increasing sequence; no duplicate intents; no outcome without intent; one terminal outcome per key; one terminal session state; compensation must reference a recorded intent) — derived from ADRs but enumerated and enforced at the assistant's discretion.
23. **Model re-execution semantics**: after a crash, an unfinished model call re-executes using the *recorded* `PromptJson` but the *currently configured* client — if the model was swapped between crash and resume, the recorded `ModelId` and the executing model diverge. Known, undecided.
24. Upcaster guard: an upcaster that fails to increase `schemaVersion` throws.
25. `Approvals.ResolveAsync`: idempotent (already-resolved returns success); assigns `Sequence = last + 1` with **no concurrency control** (see §5).
26. Denial reason string format (`"approval denied by {id}"`); denied approvals route through the standard saga unwind.
27. Session final state = **last step's result** (not an aggregate of all steps).
28. Env-var contract names: `AURELIA_SIGNAL_DIR`, `AURELIA_FAIL_NOTIFY`, `AURELIA_STEP_DELAY_MS`, `AURELIA_MODEL_ENDPOINT/MODEL_ID/API_KEY`, plus standard `OTEL_*`.
29. **Demo pacing hook inside the driver** (`AURELIA_STEP_DELAY_MS` read in the retry loop): a production code path that reads an env var for demo purposes. Deliberate, documented, but it is test/demo scaffolding living in the engine.
30. OTel span names (`session.run`, `execute_tool`, `invoke_model`, `compensate_tool`) and GenAI-semconv attribute choices; exporters gated on env vars.

### Product/demo choices

Reference-agent business rules: approval threshold **$30**, policy string `contact-center-manager`, question wording; case fixtures (42/Contoso/$25, 7/Fabrikam/$40); ledger record shape `{key, type, caseId, amountUsd, reverses}`; ledger dedupe-by-key as the exactly-once mechanism; `lookup_case` parses the case id by **stripping all non-digits** (crude by design).

34. Playground: entire design — worker-per-session **real process** model, SIGKILL + 2.5 s auto-restart, port 5199, `/tmp/aurelia-playground` data root, UI layout/copy/colors, "sabotage notify" checkbox, worker located in the Runtime project's own build output (dev-repo assumption).

## 5. Blocked / unsure

**Blocked (owner-side):**
- **Azure access** — owner has now offered; nothing consumed yet. First consumers when wired: Cosmos DB event store (needs `az login`, subscription choice, budget), Application Insights (traces), later Azure OpenAI. Design impact: `IEventStore` must gain optimistic concurrency in the same round.
- **Employer outside-work/IP disclosure** — gates making the repo public, publishing the blog, and the reliability benchmark. Currently the critical path for anything public.
- **Blog #1** exists as a draft explicitly requiring the owner's rewrite.
- **License** undecided.

**Unsure / known weaknesses (reviewer attention wanted):**
1. **No concurrency control on the log.** `IEventStore.AppendAsync` has no expected-sequence check; `FileEventStore`'s lock is per-process. Two drivers on one session (e.g., playground auto-restart racing a manual CLI `run`, or `approve` racing a resuming worker) could interleave appends. The single-writer assumption is currently enforced by convention only. Fix belongs in the Cosmos round (ETag/expected-sequence), but the file store should get it too.
2. **Derived-status logic exists twice** — in the driver (to act) and in the playground's `SnapshotAsync` (to display). They can drift; the display copy is untested.
3. **Failed-state JSON duplicated** between `ScriptedAgentDriver` and `ReconstructionReplayEngine` and compared as raw strings in tests — brittle to any serializer change.
4. **Turn semantics unexercised**: everything writes `TurnOrdinal = 0`; multi-turn (a real conversation) has no driver support and no ADR beyond the definitions in 0007.
5. **Session IDs are unvalidated** and used in both file paths and keys; a session id containing `/` or path characters would corrupt key parsing and paths. Local-tool risk today; must be fixed before any hosted deployment.
6. **Test/demo hooks in production paths**: `BlockableSignals` inside `ServiceCreditTool.ExecuteAsync` and the step-delay env read inside the driver. Both env-gated no-ops by default, but they are seams a reviewer may want isolated behind an injection point.
7. **Model client swap on resume** (item 23 above) needs a decision: honor recorded `ModelId` (fail if unavailable?) vs. current-config-wins.
8. **Playground has no automated tests** (manually smoke-tested: chaos kill → auto-restart → completion with exactly one ledger credit).
9. **Ledger scan is O(n) per append** (read-all-lines dedupe) — fine for demo volumes only.
10. `SessionNotCompletedException` for in-flight replay means the trace viewer will need a partial-reconstruction mode later; current behavior is a deliberate stopgap.
