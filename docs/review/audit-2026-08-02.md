## 2. ADR audit

all others Accepted. **Cosmos storage layout: yes, it is recorded — ADR-0019**
(database `aurelia`, container `events`, partition `/sessionId`, head-document

**Text-vs-code mismatches:**
- **ADR-0023** states the child session id is `{parentSessionId}.{stepOrdinal}`;
  since the multi-turn change the code produces `{parent}.{turn}.{step}`
  (`front.0.1`). The ADR was not amended.
- **ADR-0014** requires core changes to merge "through pull requests reviewed
  and merged by the project owner." Procedurally: PRs existed and the owner
  authorized merges, but **no PR has been reviewed** — the review clause is
  honored in form, not substance. (Also: the approval-expiry change touched
  only Runtime, so its direct-to-main path was compliant.)
- **ADR-0002** describes killing "mid-tool-call"; the harness now also kills
  in the *after-effect* window (`AURELIA_SIGNAL_AFTER_EFFECT`) — an extension
  consistent in spirit, undocumented in the ADR.

**Decisions made in code with no ADR** (beyond §1's UNAUTHORIZED rows):
schema v3 token fields; expiry evaluated lazily on re-drive only (no timer —
a parked session past deadline stays parked until something re-drives it);
non-call-event coordinate stamping conventions; the JSONL envelope's
CLR-type-name discriminator; retry-attempt/terminal event duplication shape.

## 7. Known weaknesses (the three an expert should poke first)

1. **The replay claim's thin joint.** For terminal sessions, reconstruction
   ≈ verified readback of the terminal event; the failed-state round-trip is
   asserted through a shared serializer function. An expert asking "show me
   replay computing a state the log doesn't already store verbatim" gets the
   open-conversation path (ADR-0031) and the substitution tests — real but
   narrower than the README's headline row implies.
2. **Conversation failure and memory edge semantics are young.** One bad
   turn terminally fails the whole conversation (unwind is session-scoped);
   the summarize due-formula is idiosyncratic; interrupted-summarization
   resume and concurrent `HandleTurnAsync` races (two writers computing the
   same next turn — ADR-0018 makes the loser fail loudly, but nothing tests
   it at turn granularity) are one-test-deep or untested.
3. **The benchmark's conflict of interest is now public.** The referee is a
   contestant; the competitor implementations, the naive-variant designs,
   and a mid-measurement Temporal timeout change (10s — which *created* the
   timeout-ambiguity finding's conditions) were all authored by the party
   the results favor. Methodology, code, and raw data are published and the
   caveats are stated — but until maintainer review happens, this is the
   repo's most attackable artifact, and it is now world-readable.
